# チェキカウント 公式サイト

GitHub Pages向けの静的サイトです。

## 公開手順
1. GitHubで新しいリポジトリを作成します。例: `chekicount-site`
2. このフォルダ内のファイルをすべてアップロードします。
3. GitHubのリポジトリで `Settings` → `Pages` を開きます。
4. `Build and deployment` の Source を `Deploy from a branch` にします。
5. Branch を `main`、Folder を `/(root)` にして `Save`。
6. 数分後に `https://あなたのGitHubユーザー名.github.io/chekicount-site/` で公開されます。

## App Store Connectに入れるURL
- サポートURL: `https://あなたのGitHubユーザー名.github.io/chekicount-site/support.html`
- プライバシーポリシーURL: `https://あなたのGitHubユーザー名.github.io/chekicount-site/privacy.html`
- マーケティングURL（任意）: `https://あなたのGitHubユーザー名.github.io/chekicount-site/`

## 公開前に変更する場所
`support.html` と `privacy.html` 内の `YOUR_EMAIL@example.com` を、実際のお問い合わせ用メールアドレスに変更してください。
