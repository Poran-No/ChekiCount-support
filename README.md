# チェキカウント 公式サイト

GitHub Pages 用の静的サイトです。

## ファイル
- `index.html` : 公式トップページ
- `support.html` : サポートページ
- `privacy.html` : プライバシーポリシー
- `style.css` : 共通デザイン
- `chekicount-app-icon.png` : サイト内のアプリアイコン
- `apple-touch-icon.png` : iPhoneホーム画面用アイコン
- `favicon-32.png` : ブラウザタブ用アイコン

## GitHub Pages
このフォルダ内のファイルをリポジトリのルートへアップロードし、
Settings → Pages → Deploy from a branch → `main` / `(root)` を選択します。
