FEATURES

毎日の記録を、ひとつのアプリで。

♡

売上をかんたん記録

チェキ枚数・販売価格・バック率や固定バックを入力して、その日の売上をすぐに記録できます。

⌗

カレンダーで確認

日ごとの実績や精算状況をカレンダーから確認。過去の記録にもすぐアクセスできます。

✓

精算状況を管理

未精算・精算済みを分かりやすく管理。精算日も残せるので、確認がスムーズです。
